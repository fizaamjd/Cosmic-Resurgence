# Cosmic Resurgence: design and implemented scope

The original [game design document](cosmic-resurgence-gdd.docx) records the broader creative vision. The preserved Unity project implements three planet levels.

## Implemented project

The build order includes the opening cutscene, main screen, Planet-1, Planet-2, Planet-3, lose scene and win scene. Gameplay scripts include astronaut movement, key collection, oxygen pickups, shared health and lives, and spaceship transitions.

## Design vision

The GDD proposes five planets: Velorra, Aquantis, Gelidon, Thaloris and Umbros. It also describes environmental hazards, specialized equipment and a wider terraforming story. These are design intentions and are not all verified implemented features. The three scene files retain their original names; they are not assigned GDD planet names without visual verification.

## Footage

The existing 14-second MP4 is the original introductory cutscene. It does not demonstrate all three playable levels. A full gameplay capture requires running the original complete Unity project or its preserved Windows build.
